# 게임 로비

친구들과 방을 만들고 가볍게 경쟁하는 온라인 미니게임 플랫폼입니다. 한 방에는 최대 10명이 들어갈 수 있고, 게임별 최대 인원을 넘는 사용자는 관전자로 참여합니다.

## 게임

오목, 끝말잇기, 그림 맞히기, 초성 퀴즈, 같은 답 피하기, 라이어 게임, 사목, 캐주얼 체스, 밀어내기를 제공합니다.

## 주요 기능

- 공개·비밀번호 방 생성, 방 목록 검색과 상태 필터
- 전체 채팅, 접속자 검색, 개인 메시지
- 버튼을 눌렀을 때만 열리는 채팅 서랍
- D1 기반 방·메시지·게임 상태 동기화
- 재접속, 관전, 게임 중 이탈 복구
- 결정적 게임 엔진과 자동 규칙 테스트

## 실행

Node.js 22.13 이상과 pnpm이 필요합니다.

```bash
pnpm install
pnpm dev
```

검증은 `pnpm test`로 실행합니다. 하네스 구조는 [HARNESS.md](./HARNESS.md)에 정리되어 있습니다.
