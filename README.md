# 게임 로비

친구들과 방을 만들고 가볍게 경쟁하는 온라인 미니게임 플랫폼입니다. 한 방에는 최대 10명이 들어갈 수 있고, 게임별 최대 인원을 넘는 사용자는 관전자로 참여합니다.

## 게임

오목, 끝말잇기, 그림 맞히기, 초성 퀴즈, 같은 답 피하기, 라이어 게임, 사목, 캐주얼 체스, 우노, 윷놀이, 다빈치 코드를 제공합니다.

- 우노: 2~10명, 같은 색·숫자·기호 카드 또는 와일드 카드를 내고 손패를 먼저 비우면 승리
- 윷놀이: 2~4명, 윷을 던져 말을 이동하고 잡거나 업은 뒤 네 말을 먼저 완주하면 승리
- 다빈치 코드: 2~4명, 타일을 뽑아 상대의 숨은 숫자를 추리하고 마지막까지 암호를 지키면 승리
- 끝말잇기: 종성이 있는 음절까지 두음법칙을 적용하며, 한 사람당 20초가 지나면 탈락하고 마지막 생존자가 승리

그림 맞히기는 라운드당 60초 뒤 정답을 5초 동안 공개하며, 그림 맞히기와 초성 퀴즈는 방 생성 시 3·5·7·10라운드 중 하나를 선택할 수 있습니다.

## 주요 기능

- 공개·비밀번호 방 생성, 방 목록 검색과 상태 필터
- 전체 채팅, 접속자 검색, 개인 메시지
- 버튼을 눌렀을 때만 열리는 채팅 서랍
- D1 기반 방·메시지·게임 상태 동기화
- 재접속, 관전, 게임 중 이탈 복구
- 결정적 게임 엔진과 자동 규칙 테스트
- 기본 단어 사전과 Supabase `word_dictionary` 확장 조회

## 실행

Node.js 22.13 이상과 pnpm이 필요합니다.

```bash
pnpm install
pnpm dev
```

검증은 `pnpm test`로 실행합니다. 하네스 구조는 [HARNESS.md](./HARNESS.md)에 정리되어 있습니다.

Supabase 단어 사전을 사용할 때는 `supabase/word_dictionary.sql`을 실행한 뒤 `SUPABASE_URL`과 `SUPABASE_ANON_KEY`를 서버 환경 변수로 설정합니다. `SUPABASE_ANON_KEY`에는 기존 anon 키 또는 최신 `sb_publishable_` 키를 사용할 수 있습니다. 값이 없을 때는 584개 단어가 들어 있는 내장 사전을 사용합니다.
